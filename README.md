# 战斗模拟（combat-sim）

表驱动的战斗仿真引擎：从框架工作簿读取构筑、技能、怪物、场景与批跑任务，按行为规则完成一场对战，并可选择写回运行结果。

本仓库**不包含**项目框架表或任何业务数据。请自备工作簿，并通过环境变量或 `-w` 指定路径。

## 能力

- 任务驱动管线：加载 → 编译实体 → 单场结算 → 可选写回
- 缺生命等关键字段时跳过对阵，不发明默认血量
- 怒气 / 能量 / 魔法值仅在面板提供初值时建池
- 伤害、治疗、护盾按表内「战斗流程」与「公式参数」结算
- 规则模式按行为表优先级选技能；推演模式按单位时间收益选技能
- 未接入的表列记入「待对齐」，不静默填默认值

## 布局

```
combat-sim/
  启动_战斗模拟.py      # 主入口
  公共/                 # 工作簿 I/O、表名常量、路径发现
  战斗模拟/
    pipeline.py         # 任务编排
    load/               # 按块名/字段名读表
    compile/            # 面板与怪物属性编译
    sim/                # 选技与数值解析式结算
    write/              # 写回对战模拟运行结果
  requirements.txt
  LICENSE
```

## 同级依赖

将下列仓库克隆到同一父目录后，启动脚本会自动加入 `sys.path`：

| 仓库 | 用途 |
|------|------|
| `numeric-ssot` | 框架表加载与只读校验 |
| `scene-coverage` | 场景覆盖率（可选） |
| `attr-value` | 属性边际价值（可选） |
| `scene-balance` | 多场景平衡提案（可选） |

## 环境

| 变量 | 说明 |
|------|------|
| `BATTLE_SIM_WORKBOOK` | 框架工作簿绝对/相对路径（推荐） |
| `FRAMEWORK_WORKBOOK` | 同上，等价别名 |
| `FRAMEWORK_DIR` / `BATTLE_SIM_DIR` | 含 `战斗数值框架.xlsx` 的目录 |

未设置时，依次尝试：当前工作目录、本仓库、同级 `数值框架/`。

## 运行

需要 Python 3.11+。

```bash
pip install -r requirements.txt
set BATTLE_SIM_WORKBOOK=path\to\框架表.xlsx
python 启动_战斗模拟.py
python 启动_战斗模拟.py --task 木桩场_基线 --write
```

辅助入口 `启动_DES木桩.py` / `启动_首领对战.py` 已收敛为提示，请统一使用主入口。

运行产物默认写到本仓库 `out/`（已 gitignore）。
