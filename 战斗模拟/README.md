# 战斗模拟

读战斗数值框架里的构筑、技能、怪物、场景和批跑任务，按行为规则打一场。不读场景覆盖。

```
战斗模拟/
  pipeline.py     任务 → 编译 → 一场 → 写回
  load/           按块名和字段名读表，技能等级继承
  compile/        玩家面板、怪物属性覆盖。缺生命就停
  sim/            规则选技能，数值解析式结算
  write/          追加到对战模拟的运行结果
```

```bash
cd 数值工具
python 启动_战斗模拟.py
python 启动_战斗模拟.py --task 木桩场_基线 --write
```

开场用 Excel 把流派面板终值算一次，抄进内存。怒气、能量、魔法值只在面板有初始值或当前值时才建池。战斗中的属性加减只发生在内存里。

伤害、治疗、护盾按「战斗流程」逐步执行，免伤和暴击用「公式参数」里的表达式和 Xklc 系数。场地半径、间距、移速都从表里取。技能行里有值但结算还没读到的列，以及面板缺少的公式项，会记在待对齐里，不另填默认数。

规则模式下按行为表的优先级执行第一条成立的规则。任务决策模式写成推演时，才用结算结果除以锁定时间来选技能。
